# MStroy Frontend — тестовое задание (v3.2)

## Установка и запуск

```bash
npm install
npm run dev    # запуск dev-сервера
npm run build  # сборка
```

## Тесты

```bash
npm test
```

- тесты производительности `TreeStore` на 100k элементов (`src/test/TreeStore.performance.test.ts`)
- тесты Vue-компонента `TreeTable` (`src/test/TreeTable.test.ts`)
